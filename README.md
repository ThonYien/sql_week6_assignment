# SQL Joins Using Sales Database

## Author
**Thon Yien Thon**

## Project Description
This project demonstrates how to retrieve and combine related information from different tables using SQL JOIN statements in the MySQL Classic Models sales database.

## Learning Objectives
- Understand how INNER JOIN works.
- Use LEFT JOIN to retrieve matching and non-matching records.
- Use RIGHT JOIN to retrieve all records from the right table.
- Retrieve information from multiple database tables.

## Assignment Questions
The `answers.sql` file contains solutions to three tasks:

1. **INNER JOIN:** Combine employees and offices tables.
2. **LEFT JOIN:** Combine products and productlines tables.
3. **RIGHT JOIN:** Combine customers and orders tables to retrieve the first 10 orders.

## Tools Used
- MySQL
- MySQL Workbench
- Classic Models Sales Database

## How to Run
1. Open MySQL Workbench.
2. Connect to your MySQL server.
3. Select the `classicmodels` database.
4. Open the `answers.sql` file.
5. Execute each SQL query.
6. Check the results in the Result Grid.
